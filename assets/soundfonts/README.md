# Bundled SoundFonts

These files were supplied by the project owner:

- `Yamaha Upright Lite.sf2`
- `Hammond B3.sf2`
- `Papelmedia_Trumpet.sf2`

They are loaded directly by the pure-GDScript MIDI addon. No external synthesizer,
native extension, or pre-rendered OGG conversion is used.

SoundFonts have their own licenses, separate from the app and MIDI addon's
licenses. Confirm redistribution rights and required attribution before
publishing an app containing these files.
