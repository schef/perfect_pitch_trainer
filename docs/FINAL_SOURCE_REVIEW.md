## Class 24: final recall and optional polish

### Final recall is a real consecutive-correct criterion

Raw **1567.14–1610.96** is decisive:

- **1567.14–1578.58:** “from time to time throughout a day.”
- **1578.74–1590.78:** whenever desired, sing **one tone**, then check; twenty correct.
- **1590.78–1604.78:** can be done “over a period of many days.”
- **1604.78–1610.96:** “20 in a row correctly” is the final verification round.

Keep the target at **20 consecutive correct**, not 10, twenty eventually, twenty every day, or a speed test. An incorrect checked attempt breaks the streak. Persistence across days is source-compatible and practically important. There is **no prescribed minimum delay**, number of days, daily quota, or fixed checking device/tolerance. One-attempt-then-close/no-auto-next is a labeled app way to encourage spacing, not a verbatim source interface requirement. A sounding check before credit fits “sing ... then check”; self-report is not microphone verification.
